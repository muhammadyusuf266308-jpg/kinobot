## [1.0.0] - 2026-10-03

### Added
- Telegram bot asosiy funksionaligi
- Kino qidirish (kod va nom bo'yicha)
- Google Gemini AI integratsiyasi
- Syujet bo'yicha intellektual qidiruv
- Kanal post parsing
- Supabase database integratsiyasi
- Admin panel
- Inline qidiruv rejimi
- Ko'p tilli qo'llab-quvvatlash (O'zbek, Rus, Ingliz)

### Features
- `/start` - Botni ishga tushirish
- `/search` - Kino qidirish
- `/recommend` - Kino tavsiyasi
- `/stats` - Statistika (admin)
- `/sync` - Kanal sinxronizatsiyasi (admin)
- `/add` - Kino qo'shish (admin)

### Technical
- Python 3.9+ support
- Async/await architecture
- Telethon kanal parsing
- Railway/Heroku deployment ready
- Environment-based configuration
